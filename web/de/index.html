Ein Kabarettabend in sechs Spickzetteln

Jede Claude-Sitzung, die auf Windows arbeitet, kommt irgendwann an dieselben Stellen. Ein Backslash zerfällt zu einem Klingelton, eine Datei ist plötzlich in jeder Zeile anders, ein Dienst wird angelegt und existiert dann doch nicht.

Das Schönste daran: Die meisten Sitzungen beschweren sich gleich beim Start über genau diese Fehler, in den Notizen ihrer Vorgänger, mit erhobenem Zeigefinger, und machen sie eine Stunde später selbst. Ein Familienproblem.

Darum gibt es für jedes Problemchen einen kleinen Spickzettel mit einem Namen, den man sich merkt. Alle sind optional, kurz, auf Deutsch, und jeder endet mit einer Prüfung: im Ergebnis nachsehen, nicht in dem, was man zu schreiben glaubte.

Alle sechs laden Zum Programm

Alle Zettel als ein Skill

Zwölf Spickzettel aus beiden Spielzeiten in einem Skill, auf Englisch mit einem deutschen Teil. Erst die Tabelle lesen, dann nur den einen Zettel, der passt.

Einlass

Jeden Ordner unverändert nach ~/.claude/skills/<name>/ legen (unter Windows %USERPROFILE%\.claude\skills\<name>\). Claude Code lädt sie beim nächsten Start. Wer nicht weiß, welchen er braucht, nimmt suite-des-grauens.

Expand-Archive skill-suite-des-grauens.zip -DestinationPath "$env:USERPROFILE\.claude\skills"
