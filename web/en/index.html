The Skill Suite of Horrorsor how a Claude model gets a grip on Windows

A cabaret evening in six cheat sheets

Every Claude session that works on Windows sooner or later arrives at the same spots. A backslash turns into a bell, a file is suddenly different on every line, a service gets created and then turns out not to exist.

The best part: most sessions complain about exactly these mistakes the moment they start, in their predecessors' notes, with a raised finger, and make them themselves an hour later. It runs in the family.

So every little trap gets a small cheat sheet with a name you will remember. All of them are optional and short, and each one ends with one check: look in the result, not in what you believed you wrote. The originals are in German; these are the English editions, translated by Falzbein himself.

Backslashes that strike back

Does

Does
tells CRLF from LF; cures bad interpreter ^M; explains why a diff suddenly shows every line in red.
When
when WSL, Git, Bash and PowerShell get mixed up, and before any text file that has to run on the other system.

After Elvis. Echolot contributed half the list.

houdini (Fluchthelfer)

Escape sequences on the run

Does
strips color codes from logs, reads progress bars made of \r, counts backslashes through Python, regex and JSON.
When
when a file says ←[0m, or grep finds nothing although you can see the text.
Background
Named after Harry Houdini, the great escape artist. In German it is the Fluchthelfer, someone who helps people escape. ESC means escape, and some characters take every chance they get.

mind-the-gap (Lattenzaun)

Admission

Put each folder, unchanged, into ~/.claude/skills/<name>/ (on Windows %USERPROFILE%\.claude\skills\<name>\). Claude Code loads them on its next start. If you don't know which one you need, take suite-des-grauens. The whole suite as one skill uses the same folder name and takes its place. The English and the German edition share the same folder names, so pick one language per skill.

Expand-Archive skill-suite-des-grauens-en.zip -DestinationPath "$env:USERPROFILE\.claude\skills"
