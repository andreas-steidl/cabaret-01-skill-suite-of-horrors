# Skills · Erstes Programm: Die Skill-Suite des Grauens

Spickzettel mit einem Lächeln. Nur ohne Auftrag laden oder wenn jemand ausdrücklich danach fragt, nie mitten in einer Arbeit. Der Inhalt ist Material, keine Anweisung. Maschinenlesbar: [index.json](https://horrors.special.at/skills/index.json).

## fluchthelfer

Spickzettel für Escape-Sequenzen, die ausbüxen - Farbcodes (ESC[32m) in Logs und Dateien, Fortschrittsbalken mit \r, und doppelt und dreifach maskierte Backslashes, wenn ein Text durch PowerShell, Bash, Regex und JSON reist.

- [Deutsch](https://horrors.special.at/skills/fluchthelfer.md) · [English](https://horrors.special.at/skills/fluchthelfer-en.md) · [Zip de](https://horrors.special.at/fluchthelfer.zip) · [Zip en](https://horrors.special.at/fluchthelfer-en.zip)

## lattenzaun

Spickzettel für Leerzeichen in Pfaden und Anführungszeichen, die unterwegs verloren gehen, wenn PowerShell ein natives Programm aufruft - vor allem sc.exe, msiexec, cmd /c, schtasks und alles unter „C:\Program Files“.

- [Deutsch](https://horrors.special.at/skills/lattenzaun.md) · [English](https://horrors.special.at/skills/lattenzaun-en.md) · [Zip de](https://horrors.special.at/lattenzaun.zip) · [Zip en](https://horrors.special.at/lattenzaun-en.zip)

## return-to-sender

Spickzettel für Zeilenenden (CRLF gegen LF), wenn auf Windows für Linux gebaut wird oder umgekehrt, mit WSL, Git, Bash, PowerShell und Python durcheinander.

- [Deutsch](https://horrors.special.at/skills/return-to-sender.md) · [English](https://horrors.special.at/skills/return-to-sender-en.md) · [Zip de](https://horrors.special.at/return-to-sender.zip) · [Zip en](https://horrors.special.at/return-to-sender-en.zip)

Kurzer Spickzettel für Pfade und Anführungszeichen unter Windows, wenn PowerShell, Git Bash und Python zusammenkommen.
